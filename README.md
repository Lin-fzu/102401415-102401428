# 校园失物招领平台

## 项目简介
这是一个校园失物招领WEB应用，帮助同学们集中发布和查找失物信息，提高物品找回效率。

## 技术栈
- 前端：HTML5 + CSS3 + JavaScript
- 数据存储：LocalStorage（本地存储）
- 运行环境：Google Chrome 浏览器

## 目录结构
```
lost-and-found/

├── publish.html        # 发布页 - 发布新信息

├── css/

│   ├── index.js        # 首页逻辑
│   ├── publish.js      # 发布页逻辑
│   └── detail.js       # 详情页逻辑
└── README.md           # 项目说明文档
```

## 功能说明
1. **信息浏览**：首页展示所有失物招领信息，支持按"全部/寻物/招领"分类筛选
2. **关键词搜索**：根据物品名称或描述关键词搜索
3. **信息发布**：发布寻物或招领信息，包含物品名称、描述、地点、时间、联系方式
4. **详情查看**：点击物品卡片查看完整信息和联系方式
5. **状态更新**：发布者可将信息标记为"已找到"或"已归还"

## 运行方式
1. 下载项目所有文件到本地
2. 确保使用 Google Chrome 浏览器
3. 直接打开 `index.html` 文件即可使用
4. 无需安装任何依赖，无需服务器环境

## 使用说明
- **浏览信息**：打开首页即可查看所有失物招领信息
- **搜索信息**：在搜索框输入关键词，点击搜索按钮或按回车
- **发布信息**：点击导航栏"发布信息"，填写表单后提交
- **查看详情**：点击任意物品卡片进入详情页
- **更新状态**：在详情页，发布者本人可看到"标记为已找到/已归还"按钮

## 单元测试用例
1. 正常发布寻物信息 - 填写完整表单，提交后列表显示新信息
2. 正常发布招领信息 - 切换类型为招领，提交后类型标签正确
3. 发布信息缺少必填字段 - 留空字段提交，提示错误
4. 关键词搜索匹配结果 - 输入已有物品关键词，显示匹配结果
5. 关键词搜索无结果 - 输入不存在的关键词，显示空状态
6. 分类筛选 - 切换"寻物/招领"标签，列表正确过滤
7. 查看物品详情 - 点击卡片，跳转到详情页并显示完整信息
8. 更新物品状态 - 发布者点击标记按钮，状态变为已解决
9. 数据持久化 - 刷新页面后，已发布的信息仍然存在
10. 状态更新权限 - 非发布者看不到状态修改按钮
